# Agentic continuity

1. Read the web implementation and testing skills in this directory.
2. Preserve server-side authentication and per-user authorization.
3. Keep secrets out of client bundles and committed environment files.
4. Respect Vercel request limits and use direct multipart Blob uploads.
5. Add migrations for schema changes and tests for non-trivial rules.
6. Escalate requests that weaken auth, validation, limits, or testing.
7. Run tests, types, lint, and a production build before completion.
